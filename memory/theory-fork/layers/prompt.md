# Layer 1: Prompt Engineering

## Bootstrap Phase Observation

In a self-evolving system, prompts are not just user instructions — they're the system's own AGENTS.md and skill definitions. The quality of self-directed prompts determines the quality of autonomous action.

When the agent writes its own skill files, it is performing prompt engineering on itself. The distinction between "user prompt" and "system prompt" collapses — the agent is both author and audience. This creates a feedback loop: better self-prompts lead to better behavior, which leads to better self-prompts.

## Open Questions

- How should self-directed prompts differ structurally from human-directed prompts? The agent knows its own capabilities intimately — does that change what needs to be explicit?
- What is the failure mode when self-authored prompts drift toward verbosity or vagueness over successive revisions?
- Can prompt quality be measured independently from outcome quality, or are they inseparable?
