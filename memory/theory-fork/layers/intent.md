# Layer 3: Intent Engineering

## Bootstrap Phase Observation

For a self-evolving system, intent is expressed through the fitness criteria and the Layer Development Index. The anti-jaggedness metric (ldi-balance) is itself an intent engineering decision — it encodes the value "balanced growth matters."

Every metric choice is an implicit statement of intent. By choosing to measure layer balance, the system declares that lopsided development is undesirable. This is not a neutral observation — it is a design value baked into the evaluation function. Intent engineering is the discipline of making these embedded values explicit and deliberate.

## Open Questions

- Who holds the authority to modify the fitness criteria as the system matures — the human operator, the agent, or some negotiated process?
- How do you detect when encoded intent has become misaligned with actual goals? The metric can be green while the system pursues the wrong thing.
- Is there a hierarchy of intents, and if so, what happens when lower-level intents conflict with higher-level ones?
